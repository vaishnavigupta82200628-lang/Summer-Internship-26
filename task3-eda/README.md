# Task 3: Data Preprocessing & Exploratory Data Analysis (EDA)

## Status: Completed

This task focused on practicing data cleaning and exploratory data analysis using Pandas and NumPy — handling missing values, cleaning messy columns, filtering invalid data, and reshaping datasets for analysis.

## What I Learned
- Loading and inspecting real-world messy datasets
- Handling missing/invalid values (converting text like 'Dry' to NaN)
- Cleaning column names and categorical values
- Reshaping data from wide to long format
- Grouping and aggregating data with Pandas

This built the data-handling foundation used directly in the data journalism project (Task 4).
